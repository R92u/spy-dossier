# Экспериментальные микрофоны Discord

## Установка на Aurorix

Рядом с существующим app.py загрузите spy_bridge.py и spy_boot.py. В «Запуск → APP PY FILE» замените app.py на spy_boot.py и перезапустите бот. Исходный app.py и его команды сохраняются. Для отката верните APP PY FILE = app.py после ~spy_disconnect.

Нужны Python 3.10+, discord.py 2.4+ и aiohttp (зависимость discord.py). Боту нужны Guild Members / Voice States intents и право Mute Members в выбранном канале. Интеграция не передаёт Discord-токен на сайт. Адрес игры по умолчанию https://spy-dossier.onrender.com; необязательная переменная SPY_GAME_URL переопределяет его.

## Привязка

1. Каждый участник открывает «Профиль → Привязать Discord» на главной странице или в лобби и один раз отправляет боту `~spy_link ЛИЧНЫЙ_КОД` со своего Discord-аккаунта. Для этого не нужно находиться в голосовом канале. Поддерживается и `/spy_link`.
2. Подтверждённый профиль сохраняется в localStorage этого браузера. Подпись сервера защищает привязку от подделки; она переживает новые лобби, новые сессии и перезапуски Render. Очистка данных сайта или «Отвязать Discord» удаляет сохранение в браузере. Другой браузер нужно привязать отдельно.
3. Ведущий включает «Экспериментальная игра», выбирает радиус и нажимает «Подключить голосовой канал». Находясь в нужном войсе, отправляет `~spy_connect КОД_КАНАЛА`. Канал подключается отдельно для каждого лобби.
4. Игроки с сохранёнными профилями подключаются автоматически, без новых кодов. Всем, включая ведущего, нужно зайти в этот войс. Один Discord может занимать только одно место в лобби.
5. Старые `~spy_join` и slash-команды совместимы с прежними разовыми кодами. Бот удаляет сообщение с кодом, когда у него есть Manage Messages; ответ исчезает через 30 секунд.

### Настройка сохранения профилей

Укажите одинаковый случайный секрет (минимум 32 символа) в `SPY_PROFILE_SECRET` веб-сервиса Render и в окружении бота. Альтернатива для бота — приватный файл `.spy-profile-key` рядом с `spy_bridge.py`. Секрет разрешает боту подтверждать аккаунты; храните его отдельно от исходников и архивов. Не меняйте его при обычном обновлении: смена делает старые сохранённые привязки недействительными. База данных не нужна. Подтверждения принимаются только от бота с этим секретом; браузер получает подписанный персональный пропуск.

## Поведение

- Раздача досье и выбор первого игрока: все люди в выбранном войсе получают серверный мут, включая ведущего и неиграющих зрителей. Другие боты не затрагиваются.
- Ход: говорит текущий игрок и N живых соседей с каждой стороны по кругу. Радиус 0 оставляет только текущего игрока; 1 даёт трёх говорящих; 2 — до пяти. Выбывшие места пропускаются.
- Голосование и угадывание: бот снимает свои мьюты со всех.
- Конец, закрытие лобби, отключение режима: бот снимает свои мьюты.
- ~spy_disconnect отключает управление каналом; ведущий также может отключить связь кнопкой на сайте до раунда.
- Уже наложенный до игры серверный мут не снимается. Собственный self-mute пользователя бот изменить не может.

Бот проверяет состояние примерно каждые 0,8 секунды. Смена микрофона зависит также от задержек и ограничений Discord. При сетевой ошибке он пытается снять свои мьюты и повторяет восстановление. Журнал .spy-voice-state.json нужен для восстановления после перезапуска; не удаляйте его и не публикуйте (содержит токены привязки и Discord ID). Вышедший из Discord участник восстанавливается при следующем подключении. При полностью остановленном боте или отозванных правах немедленное восстановление технически невозможно — после запуска/возврата прав бот повторит его.

Секреты исходного app.py рекомендуется перенести в окружение BOT_TOKEN и DOTA_ADMIN_SECRET и перевыпустить, если они были раскрыты. spy_boot.py запускает оригинальный app.py как __main__, подключив модуль непосредственно перед bot.run. Исходные настройки токена сохраняются. Файл app.env.py в архиве — необязательный шаблон с секретами в окружении; не заменяйте им app.py до настройки переменных. Оригинальный app.py не публикуется в репозитории игры.
