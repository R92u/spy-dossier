# Шпион — секретное досье

Игра для компании в Discord: ведущий, 3–12 игроков, тайное слово, голосование и угадывание в прямом эфире. Аккаунты и чат не нужны.

## Запуск

Node.js 22 или новее. Внешних зависимостей нет.

```sh
node server.js
node --test
```

Откройте http://localhost:3000. Порт задаётся переменной PORT. Сервер слушает 0.0.0.0; проверка готовности: GET /healthz.

## Правила

1. Ведущий создаёт лобби. Игроки вводят имя и код.
2. Ведущий задаёт слово, тему и подсказку, выбирает шпиона вручную или случайно.
3. Мирные получают слово и тему. Шпион получает тему; подсказка доступна ему, только если он ходит первым. Ведущий видит всё и не голосует.
4. Игроки подтверждают просмотр ролей. Порядок мест и ходов случайный и фиксируется на раунд. Текущий игрок или ведущий передаёт ход; число кругов не ограничено.
5. Любой живой игрок может начать голосование. Оно длится 30 секунд, ход приостанавливается. Нужны голоса строго больше половины живых участников; воздержание не уменьшает порог. Голос нельзя менять. При отсутствии большинства никто не выбывает.
6. Изгнанный мирный становится наблюдателем. Пойманный шпион проигрывает. Если остались шпион и один мирный, шпион побеждает.
7. Шпион может начать угадывание во время ходов или голосования. Голосование отменяется. Все видят ввод в реальном времени. Правильный ответ приносит победу шпиону, неверный — мирным. Регистр, лишние пробелы и ё/е не учитываются. После отправки повторной попытки нет.
8. Новый раунд открывает ведущий.

## Экспериментальные правила

Настраиваются ведущим в лобби до старта. Микрофоны Discord включаются отдельно; остальные правила работают и без бота.

- **Спец игра:** после открытия обложки мирному один раз выдаётся слово на 1 секунду. До конца раунда повторно посмотреть его нельзя. Сервер не передаёт слово до открытия и после истечения срока.
- **Больше шпионов:** 2–5 шпионов, при старте мирных должно быть больше. Можно включить видимость напарников. Ведущий выбирает первого шпиона, остальные назначаются случайно. У каждого своя случайная способность и заряд, если способности включены. Верная догадка любого или численное равенство с мирными — общая победа шпионов; неверная догадка любого — общее поражение. Мирные побеждают, изгнав всех шпионов.
- **Все за одно:** нет шпионов, все игроки видят только тему и по очереди задают вопросы ведущему. Текущий игрок может предложить ответ: правильный завершает раунд общей победой, неправильный передаёт ход. Попытки не ограничены. Режим выключает остальные игровые эксперименты, голосования, способности и управление Discord.
- **Проблемы с микрофоном:** шанс 1–100% выбирается в лобби. Со второй секунды хода сервер делает одну проверку в секунду; при срабатывании ход переходит дальше. С Discord прерванный игрок остаётся заглушён до конца следующего хода, в том числе при перешёптываниях. Голосование и угадывание приостанавливают проверки и открывают микрофоны.

В настройках оформления пять последовательных переключений «Тестовый дизайн» открывают тему **femboy**. Она сохраняется только в браузере и не меняет правила игры.

## Данные и подключение

Имя и личная статистика хранятся в localStorage браузера. Сессионный ключ в sessionStorage позволяет восстановить место после обновления страницы в той же вкладке. При потере связи место сохраняется 90 секунд. После этого игрок выбывает; уход ведущего закрывает лобби. Отдельные вкладки предназначены для отдельных игроков.

Лобби хранятся в памяти одного процесса: рестарт/деплой сервера закрывает текущие партии. Не запускайте несколько экземпляров без общего хранилища. Личные роли передаются только соответствующему участнику, секретное слово не отправляется шпиону до окончания раунда.

## Render

Web Service, Node, branch main, region Frankfurt, plan Free. Build command: `node --test`. Start command: `node server.js`. HTTP health check (если настраивается): `/healthz`. Никаких ключей, Firebase или базы данных не требуется.

## Проверки

`node --test` проверяет тайну ролей, очередность, запрет чужих действий, большинство и воздержание, изгнание мирного, победы обеих сторон, live-ввод, отмену голосования угадыванием, восстановление соединения, закрытие лобби ведущим и HTTP/SSE транспорт.
